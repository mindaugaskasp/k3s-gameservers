Enshrouded deployed as StatefulSet "{{ include "enshrouded-server.fullname" . }}".

Check status:
  kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }}
  kubectl -n {{ .Release.Namespace }} logs -f {{ include "enshrouded-server.fullname" . }}-0 -c gameserver

Players join on UDP {{ .Values.service.nodePorts.game }} with a role password
(roles in values). Settings not covered by values go in
/opt/enshrouded/server/enshrouded_server.json, which the image rewrites from
the SERVER_* env vars on every boot.

Updates and backups are the image's own crons; the first boot downloads the
game, so it stays unreachable for a while.

Metrics:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "enshrouded-server.fullname" . }}-metrics {{ .Values.statusMetrics.port }}:{{ .Values.statusMetrics.port }}
  curl localhost:{{ .Values.statusMetrics.port }}/metrics
