Project Zomboid deployed as StatefulSet "{{ include "zomboid-server.fullname" . }}".

Check status:
  kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }}
  kubectl -n {{ .Release.Namespace }} logs -f {{ include "zomboid-server.fullname" . }}-0 -c gameserver

Server name, mods and most settings come from values (server.name,
server.mods/workshopItems, etc). Map selection and anything else not
covered by values goes in server.ini/SandboxVars.lua under
/project-zomboid-config by hand, or over RCON.

Metrics:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "zomboid-server.fullname" . }}-metrics {{ .Values.statusMetrics.port }}:{{ .Values.statusMetrics.port }}
  curl localhost:{{ .Values.statusMetrics.port }}/metrics
